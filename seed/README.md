# Agentis — The Seed

**이 파일 하나가 당신의 에이전트입니다.** 다른 인프라 필요 없습니다. 복붙 + '안녕' 으로 시작합니다.

씨앗 파일은 **`agentis.md`** 하나입니다. 이걸 Cline(또는 cline SR) 워크스페이스 룰로 넣고 "안녕"이라고만 하면, 에이전트가 인터뷰를 거쳐 자기 정체성과 "두뇌"(`agentis/`)를 스스로 만듭니다.

## 설치 (둘 중 하나)

**방법 1 — 단일 룰 파일**
작업 폴더(프로젝트 루트)에 `.clinerules` 라는 파일을 만들고, `agentis.md` 내용을 그대로 붙여넣으세요.

**방법 2 — 룰 디렉토리** ✅ 추천
작업 폴더에 `.clinerules/` 폴더를 만들고 그 안에 `agentis.md` 를 그대로 넣으세요. (다른 룰과 함께 쓸 때 편하고, 확장에 유리합니다.)

## 시작

Cline 대화창에 **`안녕`** 이라고 입력하세요. 에이전트가:
1. 이름을 지어달라고 합니다.
2. 무슨 업무를 도울지 짧게 인터뷰합니다 (한 번에 한 질문).
3. 설계 요약을 보여주고 승인받으면 `agentis/` 구조를 만듭니다.
4. 사용법을 안내하고 첫 업무를 묻습니다.

이후 세션이 바뀌어도 `agentis/` 의 기억을 읽고 이어서 진행합니다. `agentis/graph/index.html` 을 브라우저로 열면 지식이 쌓이는 모습이 보입니다.

## 만들어지는 것

```
agentis/
  agent.md          # 에이전트 정체성 (이름·목적·범위·검증 포인트·경계·성공기준)
  memory/           # "두뇌" — 살아있는 LLM-위키 (세션 간 기억의 전부)
    _index.md  overview.md  log.md  hot.md
    concepts/  entities/  sources/
  skills/           # 에이전트가 키워가는 스킬 (md + 가능하면 .py)
  workflows/        # 업무 워크플로우 (md + 가능하면 .py)
  graph/            # 그래프 산출물 (D3 HTML / graphify 출력)
```

> `agentis/` 는 각 사용자의 작업 폴더에 생기는 것입니다. 이 레포(`agentis`)에는 **씨앗과 키트만** 들어있습니다.

## 더 풍부하게

`kit/` 폴더(인터뷰 스크립트·워크플로우 템플릿·스킬 라이브러리·메모리 스캐폴드·그래프 뷰어)를 작업 폴더에 복붙하고 "이 폴더 보고 셋업해줘"라고 하면 더 갖춰진 상태로 시작합니다. (개발 중)
