# 프로젝트 정리 워크플로우

프로젝트 폴더의 중복/임시/생성물 후보를 안전하게 정리한다.

## 원칙

- 삭제하지 않는다.
- 기본 실행은 보고서만 만든다.
- 적용 시에도 `_archive/agentis-cleanup-YYYY-MM-DDTHHMMSS/` 로 보관 이동한다.
- `.git`, `agentis`, `.clinerules`, `_archive` 는 기본 제외한다.
- 정리 결과는 `agentis/memory/log.md` 와 보고서에 기록한다.

## 사용

```bash
python agentis/workflows/프로젝트-정리.py
python agentis/workflows/프로젝트-정리.py --apply
```

## 완료 보고에 포함할 것

- 후보 수
- 실제 보관 이동 여부
- 보관 위치
- 사용자가 직접 삭제해도 되는 목록
- 정리 후 검증 결과
