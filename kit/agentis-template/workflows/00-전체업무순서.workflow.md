# 전체업무순서 워크플로우

## 목적

사용자가 “오늘 업무 진행해”, “정해진 순서대로 해줘”, “이 프로젝트 업무 해줘”처럼 포괄적으로 요청했을 때, Cline이 헤매지 않고 확정된 업무 흐름을 따라가게 하는 오케스트레이터입니다.

## 절차

1. **상태 확인**
   - `agentis/agent.md` 를 읽어 에이전트 이름, 목적, `primary_tasks` 를 확인한다.
   - `agentis/memory/hot.md`, `agentis/memory/log.md` 마지막 20줄을 읽어 진행 중/대기 중 업무를 확인한다.

2. **업무 분류**
   - 사용자 요청이 `primary_tasks` 중 어느 항목인지 분류한다.
   - 해당하지 않으면 부수 업무로 처리할지, 새 주요 업무/workflow로 추가할지 사용자에게 한 가지만 묻는다.

3. **기능별 workflow 선택**
   - `.clinerules/workflows/` 에 해당 업무명 또는 가장 가까운 workflow가 있으면 그 파일을 따른다.
   - 없으면 `agentis/workflows/` 에 있는 `.workflow.md` 를 확인한다.
   - `agentis/workflows/` 에만 있고 반복/확정 업무라면 업무 종료 전 `.clinerules/workflows/<업무>.md` 로 동기화한다.

4. **실행**
   - 가능한 단계는 Python 스크립트로 처리한다.
   - 기존 스크립트가 있으면 재사용하고, 없으면 `agentis/workflows/<업무>.py` 로 만든다.
   - 입력/출력 경로를 명확히 두고, 작업 로그를 남긴다.

5. **검증**
   - 산출물 존재 여부, 항목 수, 샘플 대조, 포맷 검사 등 업무에 맞는 실제 검증을 실행한다.
   - 검증하지 못한 항목은 “미검증”으로 보고한다.

6. **정리와 기억 갱신**
   - `agentis/memory/log.md` 에 `[primary:N]` 또는 `[aux]` 태그로 기록한다.
   - `agentis/memory/hot.md` 를 현재 상태 기준으로 갱신한다.
   - 필요한 concept/entity/source 페이지를 갱신한다.

7. **시각화 갱신**
   - 기억, 주요 업무, `.clinerules/workflows/` 가 바뀌면 `python agentis/graph/refresh_views.py --workspace .` 를 실행한다.
   - 이 명령은 루트 `workflows.html`, 루트 `holonomic-brain.html`, 기존 `agentis/graph/graph.html`, `agentis/graph/flow.html` 을 함께 갱신한다.
   - 능력치가 필요하면 이어서 `python agentis/graph/agent-stats.py` 를 실행한다.
   - 실패하면 실패 이유를 보고한다.

8. **보고**
   - 완료/미완료, 사용한 workflow, 산출물, 검증 결과, 남은 사용자 확인사항을 짧게 보고한다.

## 주의 / 엣지 케이스

- 이 파일은 모든 세부 절차를 담는 곳이 아니다. 전체 순서만 잡고, 세부 업무는 기능별 workflow로 분리한다.
- Cline의 공식 workflow 호출은 slash 기반일 수 있으므로, 자연어 요청에서는 `.clinerules/10-agent-routing.md` 의 라우팅 규칙과 함께 이 파일을 참조한다.
- `agentis/workflows/` 만 갱신하고 `.clinerules/workflows/` 를 갱신하지 않으면 Cline Workflows 탭에서 누락될 수 있다.
