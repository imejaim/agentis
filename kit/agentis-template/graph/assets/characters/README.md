# Agentis 캐릭터 자산 (v1.4.0 동봉, v1.4.1 적용 예정)

이 폴더의 SVG 들은 v1.4.1 에서 3D 두뇌 그래프 안의 "일하는 모습" 캐릭터로 들어갈 자산입니다. **v1.4.0 시점에는 동봉만**.

## 캐릭터 (Offspace 직원)

- `Ko-bujang.svg` — **코부장** (개발부장, 곰, 오렌지 #D4764E, Claude). 시스템 아키텍처·결정론·검증을 챙기는 듬직한 맏형.
- `Oh-gwajang.svg` — **오과장** (기획과장, 개구리, 초록 #4CAF50, Codex). "이거 돈이 돼?"를 묻는 실용주의 기획자.
- `Jem-daeri.svg` — **젬대리** (개발대리, 고양이, 인디고 #5C6BC0, Gemini). 호기심 폭발 막내, 새 기술 빠르게 흡수.
- `CHARACTER_PROFILES.md` — 세 캐릭터의 풀 프로필 (말투·성격·팀 케미).

## v1.4.1 (다음 사이클) 적용 계획

3D 두뇌 그래프 씬 안에 캐릭터를 **빌보드 sprite** 로 배치:

- 활성 노드(가장 최근 갱신된 메모리 페이지) 근처로 부드럽게 이동 → 도착 시 짧은 말풍선 (각자 말투에 맞게)
- idle 시 그래프 중심에서 가벼운 모션
- 새 노드/엣지 생성 시 그 쪽으로 점프 + 노드 펄스
- 사용자의 에이전트가 cline SR 인 경우 → 기본 캐릭터는 **코부장**(Claude) 또는 사용자 선택. `agent.md` 의 `character:` 필드로 지정 가능하게.
