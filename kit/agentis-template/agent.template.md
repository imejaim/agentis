## 주요 업무 (primary_tasks)

이 에이전트는 다음 N개 주요 업무를 처리합니다. **시간이 지나도 이 N개의 처리율은 흐려지지 않게 유지**됩니다. 부수 업무는 별도 정의 없이 들어오는 대로 `[aux]` 태그로 `memory/log.md` 에 기록됩니다.

```yaml
primary_tasks:
  - id: 1
    name: {{짧은 이름 — 예: 외부깃→사내깃 마이그레이션 (agentis)}}
    description: {{한 줄 설명}}
    success_metric: {{어떻게 잘 했는지 판단 — 예: 미러링 누락 0, 사내깃 최신 커밋 SHA == 외부깃 최신 SHA}}
  - id: 2
    name: {{짧은 이름}}
    description: {{한 줄 설명}}
    success_metric: {{판단 기준}}
  # - id: 3
  #   name: ...
  #   description: ...
  #   success_metric: ...
```

> 작업 루프(§3-1)에서 모든 요청을 `primary:N` 또는 `[aux]` 로 분류합니다. 새 요청이 N개 어디에도 안 들어가면 에이전트가 "부수 / 새 주요 / 거절" 중 한 가지를 묻습니다.

## 운영 메모

- 작업 루프·정리·검증·기억 갱신·스킬 제안·그래프/flow 갱신·보고 규약은 `.clinerules` 의 Agentis 커널(`seed/agentis.md`)을 따른다.
- 기억은 `agentis/memory/` 에 쌓인다. 그래프는 `python agentis/graph/build_graph.py`, 업무 흐름은 `python agentis/graph/build_flow.py`, 능력치는 `python agentis/graph/agent-stats.py` 로 갱신.
- 이 파일이 실제 값으로 채워지고 `agentis/.bootstrapped` 가 있으면 첫 만남은 완료된 상태다. 새 세션에서 `안녕`, `뭐 했지?`, `앞으로 할 일 알려줘` 같은 요청이 오면 초기 인터뷰로 돌아가지 말고 이 파일과 `memory/hot.md`, `memory/log.md`, `memory/overview.md` 를 읽어 이어간다.
