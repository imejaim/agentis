# 시험성적서 항목 추출 워크플로우

## 목적
[[entities/시험성적서]] 에서 시험 항목 표를 뽑아 [[concepts/시험성적서-항목-스키마]] 형태의 csv 로 정리한다.

## 절차
1. **입력 확인** — PDF면 텍스트로 변환 (텍스트 PDF: `pdfplumber` / 스캔: OCR; 둘 다 사내 설치 가능한지 확인). 변환된 `.txt` 에 표가 `|` 구분으로 들어있어야 함. 없으면 사용자에게 표 영역을 알려달라고 요청.
2. **추출** —
   ```
   python agentis/workflows/시험성적서-항목추출.py --in <성적서.txt> --out <항목표.csv>
   ```
3. **검증** — 콘솔에 찍히는 것 확인:
   - `추출 행 수 == 원본 표 데이터 행 수` (안 맞으면 실패 — 조용히 일부만 뽑힌 것)
   - `??` 가 들어간 칸 목록 — 사람 확인 필요분 → [[hot]] 에 적기
   - 판정 `부적합` 행 — 있으면 사용자에게 강조
4. **산출물 전달** — csv + 검증 요약 + "다시 돌리는 법" 한 줄. `??`/`부적합` 명시.
5. **기억 갱신** — `memory/log.md` 에 `## [날짜] task | <모델명> 시험성적서 항목 추출 — N건, ?? M개`, 새 양식·새 항목명 만났으면 [[concepts/시험성적서-항목-스키마]]·[[entities/시험성적서]] 갱신, `hot.md` 갱신, `python agentis/graph/build_graph.py`.

## 주의 / 엣지 케이스
- **측정값을 추측하지 않는다.** 파싱 애매하면 `??`. (스캔 OCR은 특히)
- 기관별 표 양식이 다르면 파서가 5~6열 가정에서 깨질 수 있음 → 새 양식 만나면 이 스크립트의 컬럼 매핑을 보강.
- 헤더 행("시험항목 | ...")이 표 위에 있다고 가정. 없으면 사용자 확인.
