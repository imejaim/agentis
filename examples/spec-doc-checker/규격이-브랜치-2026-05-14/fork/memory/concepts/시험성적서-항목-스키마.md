# 시험성적서 항목 스키마

[[entities/시험성적서]] 에서 추출해 표로 정리하는 표준 컬럼. [[workflows/시험성적서-항목추출]] 의 `시험성적서-항목추출.py` 가 이 스키마로 출력한다.

| 컬럼 | 설명 | 비고 |
|------|------|------|
| `시험항목` | 안전/전자파/유해물질 등 시험 이름 | 필수 |
| `규격조항` | 적용한 규격·조항 번호 | 필수 |
| `요구값` | 기준치(범위·상한·하한) | 단위 포함 |
| `측정값` | 실측 결과 | 단위 포함. 못 읽으면 `??` |
| `판정` | 적합/부적합/해당없음 | 필수 |
| `비고` | 조건·예외 | 선택 |

규칙:
- **측정값을 추측하지 않는다.** OCR/파싱이 애매하면 그 칸은 `??` 로 두고 [[hot]] 에 적어 사람 확인 요청.
- 추출 끝나면 `추출 행 수 == 원본 표 행 수` 검증. 안 맞으면 실패.
- 판정이 `부적합`인 행은 사용자에게 별도 강조.
