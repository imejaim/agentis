# KC 안전인증 (엔티티)

전기용품 안전관리법에 따른 인증. 규격이가 다루는 주된 인증 종류.

## 요구 제출 문서 (현재 기준: [[sources/2026-05-10-제출문서목록-v2]])
- 인증 신청서
- 제품 설명서 / 외관도
- 회로도 (블록도 포함)
- 부품표(BOM) — 안전 관련 부품 표시
- 핵심부품 인증서 사본
- 시험성적서 → [[entities/시험성적서]]
- 사용설명서(한글)
- 공장심사 관련 자료(해당 시)

> 위 목록이 곧 체크리스트의 기본형. 제출 건이 오면 [[concepts/체크리스트-대조-원칙]] 대로 대조한다. 인증기관/제품군마다 가감 있음.
