# 체크리스트 대조

요구 체크리스트와 실제 제출 문서 목록을 대조해 **빠진 게 있는지** 찾는다. [[concepts/체크리스트-대조-원칙]] 을 코드로 옮긴 것.

## 언제
- 새 인증 제출 건 검토할 때. 적용 안 되는 경우: 체크리스트가 표/엑셀 등 한 줄=한 항목 형태가 아니면 먼저 그 형태로 정리한 뒤 쓴다.

## 절차
1. 체크리스트와 제출목록을 한 줄당 한 항목인 `.txt` 로 준비. (`#` 로 시작하거나 빈 줄은 무시됨)
2. 실행:
   ```
   python agentis/skills/checklist-대조/run.py --checklist <체크리스트.txt> --submitted <제출목록.txt> --out <대조결과.md>
   ```
3. 결과 `.md` 와 콘솔 출력 확인. **개수 검증**(대조한 항목 수 == 체크리스트 항목 수)이 콘솔에 찍힌다 — 안 맞으면 실패로 보고.
4. `누락` 항목은 사용자에게 강조. `미확인`(이름 비슷한데 동의어 사전에 없음)은 사람 확인 요청 + 확인되면 `run.py` 의 `SYNONYMS` 에 추가(= 스킬 개선).
5. `memory/log.md` 에 `## [날짜] task | <건명> 체크리스트 대조 — 누락 N건`, 새 별칭 추가했으면 `concepts/체크리스트-대조-원칙` 의 동의어 사전 메모도 갱신.

## 주의
- 동의어 사전이 핵심이다. 새 인증기관/제품군은 표현이 다르다 → `미확인`이 나오면 그냥 넘기지 말고 사전을 키워라.
- 체크리스트 새 버전이 오면 [[concepts/체크리스트-대조-원칙]] §5 대로 v1↔v2 diff부터.
