# 브랜치 비교

두 사람의 에이전트(또는 두 브랜치)를 받아 **스킬·워크플로우·개념** 디프 보고서를 만든다. **메인 큐레이션**의 입력 자료. (사람 관리자가 보고 결정)

비교 차원:
- 한쪽에만 있는 것 (=양쪽에 다 채택 후보)
- 양쪽에 같은 이름 / 내용 동일 (=이미 정렬됨)
- 양쪽에 같은 이름 / 내용 다름 (=충돌, 사람 결정 필요)
- 이름은 다른데 비슷한 의미일 가능성 (=의심 후보, 사람 확인)

## 절차

1. 두 입력 경로 준비 (브랜치 폴더면 자동으로 `fork/` 안을 들여다본다):
   ```
   python agentis/workflows/브랜치-비교.py <A 경로> <B 경로> [--out 비교결과.md]
   ```
2. 콘솔 통계 + 마크다운 보고서 확인. 항목 많으면 `--filter skills,workflows` 로 좁히기.
3. 보고서를 관리자가 보고 메인 채택안 결정 → 메인 레포에 반영.

## 출력 포맷 예
```
| 종류 | 이름 | 상태 | 비고 |
|------|------|------|------|
| skill | checklist-대조 | 양쪽-동일 | |
| skill | bom-비교 | A에만 | A의 새 스킬 — 채택 후보 |
| workflow | 시험성적서-항목추출 | 충돌 | A는 200줄, B는 250줄. H1 같음. 사람 결정 필요 |
| concept | rohs-기초 | 충돌 | 본문 길이 차이 큼 |
```

## 주의
- 내용 비교는 **정규화된 텍스트 해시**(공백/줄바꿈 정규화)로 한다. 의미적 동일성은 사람이 판단.
- "비슷한 이름" 휴리스틱은 단순(서로의 슬러그가 다른 쪽 슬러그의 prefix/suffix 인지) — 진짜 의미 매칭은 사람 몫.
