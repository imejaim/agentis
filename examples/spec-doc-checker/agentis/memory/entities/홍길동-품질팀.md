# 홍길동 (품질팀) — 사용자

규격이를 만든 사람이자 주 사용자.

## 맥락 / 선호
- 품질팀에서 규격인증 제출 패키지 검토를 담당. 제출 건이 몰릴 때 시간 압박이 큼.
- "누락이 제일 무섭다" — 빠진 문서 때문에 인증이 반려되는 게 최악. 그래서 규격이의 1순위는 **누락 0**.
- 결과는 "근거랑 같이" 보길 원함 — 숫자만 던지지 말고 대조/검증 내역을 함께. 추측은 싫어함.
- 바쁠 때는 요약만, 시간 있을 땐 상세를. 처음엔 요약으로 보고하고 "자세히" 하면 펼친다.

## 진행 중 요청
- 제출 패키지 "최종 점검 리포트" 한 장 ([[hot]], [[log]] 2026-05-12).
