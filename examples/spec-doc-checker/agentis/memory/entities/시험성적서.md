# 시험성적서 (엔티티)

공인시험기관이 발급하는, 제품이 규격 시험을 통과했음을 증명하는 문서. [[entities/kc-안전인증]] 제출물의 핵심.

## 형태
- 보통 PDF. 텍스트 PDF면 바로 파싱, 스캔 PDF면 OCR 필요.
- 본문에 시험 항목 표가 있음 → [[concepts/시험성적서-항목-스키마]] 대로 추출.

## 다루는 법 ([[workflows/시험성적서-항목추출]])
1. PDF면 먼저 텍스트로 변환 (텍스트 PDF: pdfplumber 등 / 스캔: OCR).
2. `시험성적서-항목추출.py --in <텍스트> --out <csv>` 로 표 추출.
3. `추출 행 수 == 원본 표 행 수` 검증. 못 읽은 칸은 `??`.
4. 판정 `부적합` 행 강조. 사람 확인 필요분은 [[hot]] 에.

## 알려진 한계
- **스캔 PDF OCR 품질 편차 큼** → 텍스트 추출 후 사람 1차 확인 권장. (2026-05-08 모델X 건에서 2칸 `??` 발생: [[sources/2026-05-08-시험성적서-모델X]])
- 기관별로 표 양식이 달라 파서가 깨질 수 있음 → 새 양식 만나면 워크플로우 스크립트 보강.
