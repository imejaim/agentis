# 체크리스트 대조 원칙 (누락 0)

요구 체크리스트 ↔ 실제 제출 문서 목록을 대조할 때 **누락을 절대 놓치지 않기 위한** 규칙. 이 원칙은 [[skills/checklist-대조]] 의 `run.py` 에 그대로 구현되어 있다 (결정론).

1. **정규화 후 비교** — 공백/괄호/대소문자/전각·반각/말줄임 제거하고 비교. ("회로도 (블록도 포함)" == "회로도")
2. **동의어 사전** — 자주 쓰이는 별칭을 매핑. (예: "BOM" ↔ "부품표" ↔ "자재명세서") 새 별칭 발견 시 사전에 추가.
3. **개수 검증** — `대조한 체크리스트 항목 수 == 체크리스트 파일의 항목 수` 아니면 처리 실패로 본다. (조용히 일부만 처리하는 사고 방지)
4. **결과는 3분류** — `OK`(제출됨) / `누락`(체크리스트엔 있는데 제출 목록에 없음) / `미확인`(이름이 비슷한데 동의어 사전에 없음 → 사람 확인 필요). `미확인`은 빈칸이 아니라 명시한다.
5. **버전이 바뀌면 diff 먼저** — 체크리스트 새 버전이 오면([[sources/2026-05-10-제출문서목록-v2]]) 이전 버전과 무엇이 추가/삭제됐는지부터 사용자에게 보고.
