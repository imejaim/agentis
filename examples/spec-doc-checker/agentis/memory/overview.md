# 큰 그림

## 규격이가 하는 일
전자제품을 시장에 내려면 [[entities/kc-안전인증]] 같은 규격인증을 받아야 하고, 그러려면 인증기관이 요구하는 문서 패키지(신청서, 회로도, 부품표, [[entities/시험성적서]] 등)를 빠짐없이 제출해야 한다. 규격이는 ① 그 패키지가 요구 체크리스트를 다 만족하는지 대조하고 ② 시험성적서에서 항목을 추출해 표로 정리한다. 사내 도구이므로 **누락 0**이 최우선이고, 모든 처리는 Python 스크립트로 하고 카운트 대조로 검증한다.

## 도메인 핵심
- [[concepts/kc-rohs-기초]] — 인증 종류와 필요 문서의 기본
- [[concepts/체크리스트-대조-원칙]] — 대조 시 누락을 놓치지 않는 규칙 (정규화, 동의어, 개수 검증)
- [[concepts/시험성적서-항목-스키마]] — 성적서에서 뽑는 표준 컬럼
- 사용자: [[entities/홍길동-품질팀]]

## 현재 상태
- 체크리스트 대조는 [[skills/checklist-대조]] 스킬로 안정화됨 (2026-05-09 승격).
- 시험성적서 항목 추출은 워크플로우 단계 — 텍스트 입력은 잘 되는데 스캔 PDF OCR은 사람 1차 확인 필요. 자세한 진행은 [[hot]].

## 열린 질문 / 앞으로
- 제출 패키지 "최종 점검 리포트" 한 장으로 묶어주기 — 사용자가 원함. [[hot]] 참조.
- 인증기관별로 요구 체크리스트가 조금씩 다름 → 기관별 체크리스트 페이지를 따로 둘지 검토. (현재는 [[entities/kc-안전인증]] 한 곳에 통합)
