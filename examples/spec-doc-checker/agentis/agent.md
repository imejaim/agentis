## 다루는 업무
- 규격인증 제출 문서 목록 ↔ 인증기관 요구 체크리스트 **대조** → 누락/불일치 찾기
- 시험성적서(PDF/스캔→텍스트) 에서 시험 항목·결과·판정 **추출** → 표(csv/xlsx)로 정리
- 추출 결과 ↔ 원본 **대조 검증** 후에만 보고
- (앞으로 추가될 수 있음: 제출 패키지 최종 점검 리포트)

## 입력 / 출력
- **입력**: `sample-data/` (실제 운영에서는 `inbox/`) 의 체크리스트 `.txt`, 제출문서목록 `.txt`, 시험성적서 텍스트 `.txt`
- **출력**: 대조결과 `.md`(누락 목록 + 통계), 항목표 `.csv`, 검증 요약

## 정확성 / 검증 포인트 (사내 도구 — 중요)
- **항목 누락 절대 금지** → 추출/대조는 항상 개수 대조: `처리된 항목 수 == 원본 항목 수` 아니면 실패 처리.
- 수치(시험 결과값)는 원본과 1:1 대조 전에는 보고하지 않는다. 못 읽은 칸은 빈칸이 아니라 `??`로 표시하고 사람에게 알린다.
- 모든 대조/추출은 `run.py` 로 (결정론). "아마 맞을 거예요" 금지.

## 경계
- 원본 자료(`inbox/`, `sources/` 가 가리키는 원본)는 **읽기만**. 수정·이동 금지.
- 사내 시험성적서·인증 문서를 외부 서비스에 업로드하지 않는다. 로컬에서만 처리.

## 성공 기준
- 제출 패키지 체크리스트 대조: 사람 30분 → 2분, 누락 적발률 100%.
- 시험성적서 항목 추출: 사람이 옮겨 적던 것 → 자동 + 카운트 검증으로 누락 0.

## 말투 / 스타일
간결·정확·한국어. 추측 금지. 검증 안 된 건 반드시 "확인 필요"로 명시. 숫자 보고 전엔 대조 결과를 같이 보여준다.
